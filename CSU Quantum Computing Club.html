Learning Journey Path

🧸 Beginner Start Line

Zero experience? Perfect. Start here.

  • Weeks 1–2: Basics
    Qubits, gates, measurement. Simple and visual.
  • Hands-on tools
    Try a drag-and-drop circuit tool, then run a simulator.
  • First “Hello World”
    Build a Bell state and understand what you see.
Goal: feel confident fast

🚀 Intermediate & Projects

Ready to code and build things.

  • Coding track
    Python + a quantum SDK (we’ll share starter code).
  • One main topic
    Grover / VQE / QAOA — we pick one focus track.
  • Team projects
    Small, fun, and demo-ready by the end of semester.
Goal: ship a small demo
